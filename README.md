# 똑Pay

**똑똑, 결제 전에 잠깐만요.**

무료체험·결제 전에 묻고, 가족의 의견과 다음 청구까지 이어서 확인하는 구독 관리 도우미입니다.

[웹 데모 열기](https://mmporong.github.io/kirothon-team-024/) · [발표 PDF](PRESENTATION.pdf) · [개발 보고서](BUILD_REPORT.md)

> 합성 데이터로 만든 시연입니다. 웹에서는 저장된 Kiro 점검 기록과 수동 체험을 확인하며, 실제 결제·해지·환불은 수행하지 않습니다.

## 1. 문제 정의

무료체험의 유료 전환, 결제 경로마다 다른 가격·해지 위치, 가족이 함께 쓰는 구독을 한 사람이 챙기기 어렵습니다. 해지를 요청한 뒤에도 이전 경로의 청구가 이어질 수 있습니다.

## 2. 핵심 기능

| 기능 | 할 수 있는 일 |
|---|---|
| 결제 전 점검 | 무료체험 종료일과 취소 결정 마감을 확인하고 먼저 묻기 |
| 가격 비교 | 웹·앱 결제의 표시가격과 비교 가능한 조건 확인 |
| 가족과 결정 | 반대·철회·조건 변경을 반영해 현재 제안에 다시 동의받기 |
| 다음 청구 확인 | 새 경로의 정상 청구와 이전 경로의 재청구 구분 |
| 쉬었다 돌아오기 | 기존 요금 자격을 잃는 경우 재가입 손익 계산 |

## 3. 사용 시나리오

**결제 전 질문 → 가격·조건 확인 → 가족 의견 → 결제자에게 안내 → 다음 청구 확인**

데모의 5개 장면에서 이 흐름을 골라 볼 수 있습니다. 긴 메시지와 실행 근거는 펼쳐 보고, 움직이는 Kiro 캐릭터는 정지할 수 있습니다.

## 4. 기대 효과

결제 마감·공식 처리 경로·가족의 현재 의견을 한 흐름에서 확인하도록 돕습니다. **개인의 실제 절감액과 시간 절약은 아직 측정하지 않았습니다.**

가격 자료는 46개 요금제를 담고, 같은 월간 조건을 확인한 TVING 4등급만 기본 차액 비교에 사용합니다. 조건이 불확실한 가격은 보류합니다. [가격 근거와 보류 사유](docs/evidence/price-audit.md)

## 5. 차별점

- 가족이 반대하면 조건을 바꿔 다시 동의받고, 이전 경로에서 재청구되면 같은 사건을 다시 엽니다.
- 똑이는 도구 결과와 거부 사유를 읽어 다음 행동을 고르고, 금액·동의·상태 전이는 코드가 검사합니다.
- 실제 Kiro 점검 **5회·도구 호출 34회·정책 거부 5회**를 보존했습니다. 합성 녹화이며, 녹화 뒤 수정한 소스의 Kiro 재실행 기록은 없습니다.

## 6. 설치와 실행

Node.js 22.12 이상이 필요합니다. 웹 데모는 Kiro 없이 볼 수 있습니다.

```bash
cd "$HOME/kirothon-team-024"
npm ci
npm run dev
```

새 모델 점검을 실행하는 `npm run bot:demo`는 Kiro CLI 로그인과 모델 사용 권한이 필요합니다. [실행 조건·합성 입력·한계](BUILD_REPORT.md)

**프로젝트 402/402 · 별도 합성 훅 7/7 · 브라우저 37/37 통과.** `npm run build`는 앱·Node 타입 검사와 정적 빌드를 포함합니다.
