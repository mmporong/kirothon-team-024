# 똑Pay

똑Pay(똑페이)는 무료체험·결제 전에 먼저 묻고, 결제 경로의 가격과 해지 뒤 다음 청구를 확인하는 도우미입니다.

"똑똑, 결제 전에 잠깐만요."

**Demo:** https://mmporong.github.io/kirothon-team-024/

## 1. 문제 정의

### 대상 사용자

아이폰 인앱·서비스 웹·Google Play·통신사 등 결제 경로가 나뉘고, 무료체험이나 가족 공유 구독을 함께 관리하는 사람입니다. 데모는 나(결제자)·엄마·동생의 합성 가구입니다. 개인 문자·실계정·실제 결제 기록은 쓰지 않았습니다.

### 문제 상황

무료체험 종료일과 취소 마감을 따로 챙기다 보면 계속 쓸지 정하기 전에 결제될 수 있습니다. 같은 서비스라도 결제 경로에 따라 가격과 해지 위치가 다릅니다. 경로를 바꿨는데 이전 경로에서도 청구되거나, 가족의 반대 뒤 조건을 고쳤는데 옛 동의를 그대로 쓰는 문제도 남습니다.

### 기존 방식과 한계

구독 목록·캘린더·가족 대화방과 각 서비스의 구독 화면으로 관리할 수 있습니다. [Rocket Money](https://help.rocketmoney.com/en/articles/934402-how-do-i-cancel-a-subscription-on-rocket-money)의 취소 지원, [Subly](https://play.google.com/store/apps/details?id=com.subly.lifelog&hl=ko&gl=KR)의 결제 전 알림, [페이인포](https://www.payinfo.or.kr/guide/useguideCdtrns2.do?menu=14)의 자동납부 해지·결과 확인도 있습니다. 똑Pay는 결제 전 질문, 경로별 표시가격, 가족의 현재 의견, 다음 청구를 같은 사건에 이어서 남깁니다.

### 근거

한국소비자원에는 2022년부터 2025년 1분기까지 온라인 무료체험 이벤트 관련 피해구제 신청 **151건**이 접수됐습니다. 유형에는 유료전환 고지 미흡과 무료기간 해지 방해가 포함됐습니다. 전체 구독자의 피해율을 뜻하는 수치는 아닙니다. [소비자시대 2025년 9월호](https://www.kca.go.kr/webzine/board/view?div=kca_2509&linkId=898&menuId=MENU00307), 조사 자료의 원문 확인 시각: 2026-11-14 15:38 KST.

공정위·한국소비자원 조사에서는 문제·피해를 경험한 **OTT 품목응답자 2,576명 중 5.9%**가 해지 신청 뒤 계속 청구를 경험했다고 답했습니다. 최근 1년 구독 문제·피해 경험이 있는 전국 20~60대 계정 주가입자를 대상으로 한 2025년 4월 21~30일 비확률 온라인 조사입니다. 전체 OTT 이용자의 피해율이나 위법 청구율로 일반화하지 않습니다. [「구독경제와 소비자 이슈」 표 10·표 38, 인쇄 p.32·68](https://www.ftc.go.kr/www/downloadBbsFile.do?atchmnflNo=52480), 2025-12-29 공개·조사 자료의 원문 확인 시각: 2026-11-14 15:39~15:41 KST.

### 목표

점검 봇 똑이가 등록된 자료를 살펴 결제자에게 먼저 묻습니다. 결제 경로의 표시가격과 공식 취소 절차를 보여 주고, 사람이 정한 결정을 다음 청구 확인까지 이어 갑니다. 가족의 반대나 미응답으로 정책 관문이 거부하면 사유를 읽고 재요청이나 개정안을 고릅니다. 투표·해지 신청·사업자 확인 기록은 사람이 남깁니다.

똑이는 `household` MCP 도구만 쓰며 파일·셸 도구는 거부합니다. 가족 동의·결제자 인계·해지 사건 단계는 앱과 같은 `evaluateAction`을 거칩니다. 질문 중복과 메시지 금액은 도구 코드가 검사합니다. 사람 대신 투표·동의 철회·해지 신청·사업자 확인을 기록하는 도구는 노출하지 않습니다.

웹은 **점검 데모 · 가격 비교 · 가족과 결정 · 쉬었다 돌아오기 · 작동 원리**로 나뉩니다. 점검 기록은 5개 장면에서 골라 보고, 긴 메시지와 실행 근거는 펼쳐 확인합니다. 밝은 화면에 Kiro 캐릭터와 보라색 테마를 적용했으며, 캐릭터 정지 버튼과 동작 줄이기 설정을 지원합니다.

가격 데이터는 PRICE-A 35개·PRICE-B 11개 요금제의 최종 원본을 통합한 **46개 요금제**입니다. `verified`는 공식 표시값 확인, `comparable`은 기간·세금 등 비교 조건에 대한 별도 판정입니다. `src/data/channel_price_review.json`에 보류 사유를 남기고, 보류된 공개 가격은 차액 권고에서 제외합니다. TVING 4등급은 같은 등급의 한국 기본 공개 월간가격 비교에 사용합니다.

유튜브 iOS·지니 30일권·왓챠 iOS·디즈니+ iOS와 조건 확인이 끝나지 않은 웨이브·밀리의서재·Notion은 공개 가격의 차액 권고를 보류합니다. 보조 입력의 실제 월 청구액은 사용자가 월 단위로 확인한 값일 때 현재 가격으로 우선합니다. 개인의 가입 자격·할인·최종 결제액은 별도 확인 사항입니다.

## 3. 사용 시나리오

### 결제 전 질문에서 다음 청구까지

1. **마감 전에 묻기:** 등록한 무료체험 종료일을 우선하고 결제 경로의 취소 여유를 반영합니다. 합성 예시에서 유튜브 체험은 11월 16일 종료, App Store 결정 마감은 11월 15일입니다. 11월 14일 점검은 결정 마감 D-1이며, 디즈니+ 웹 정기결제는 D-3입니다.
2. **경로 가격 확인:** 같은 월간 요금제의 공개 표시가격과 출처를 봅니다. 아래 티빙 예시는 표시가의 산술 차이입니다. 최종 청구액과 계정 적용 조건을 확인한 뒤 이동 여부를 정합니다. 월 차액의 12배는 연간권 가격이 아닙니다.
3. **공식 경로에서 처리:** 이동을 선택하면 현재 경로의 자동 갱신 끄기, 이용기간 종료 확인, 새 경로 가입, 다음 청구 확인 순서를 안내합니다. 취소·가입·환불 요청은 결제자가 처리합니다. 기존 요금 자격을 잃을 수 있는 경우에는 보조 손익 경고를 확인합니다.
4. **다음 청구 대조:** 새 경로의 예상 청구는 남기고, 해지 요청한 이전 경로의 청구가 오면 같은 사건을 다시 엽니다. 해당 채널의 공식 취소·환불 요청 경로를 안내합니다. 해지 요청 기록만으로 종료를 확정하거나 환불을 보장하지 않습니다.

### 가족과 함께 쓰는 구독

1. 나(결제자)가 가족 검토를 선택하면 똑이가 제안 v1을 남깁니다. 앱 안 합성 역할별 피드이며 실제 SMS·카카오톡 전송은 아닙니다.
2. 미응답은 `consent_missing`, 반대는 `objection_present`로 인계를 거부합니다. 똑이는 필요한 사람에게 다시 묻거나 반대 의견을 반영한 v2를 냅니다. 조건이 바뀌면 옛 동의는 현재 동의로 집계하지 않습니다.
3. 엄마·동생 등 필수 공동 사용자가 현재 버전에 동의하면 결제자에게 공식 경로를 안내합니다. 동의가 철회되면 인계를 다시 잠급니다. 가족 의견은 법적 위임이 아닙니다.

[메인 재생 기록](docs/evidence/bot-runs/20261114154741-demo-replay.json)은 위 합성 가구의 실제 Kiro 실행 결과입니다. 녹화 시점에는 29개 요금제 자료를 사용했습니다. 녹화의 유튜브 가격 차이는 당시 합성 입력과 자료에 따른 계산입니다. iOS 월간 SKU·VAT 매핑이 미확인인 유튜브 가격은 현재 검증된 절감 예시에서 보류합니다. 녹화 이후의 46개 데이터 통합과 소스 수정에 대한 Kiro 재실행 기록은 없습니다.

아래는 공개 표시값·계산 예시·합성 시나리오에서 확인한 값입니다. 실제 절감액, 수동 대비 시간 절약, 클릭 감소는 측정하지 않았습니다.

|---|---|---|

| 같은 가격을 12개월 유지하는 계산 | 2,500원 × 12 = 30,000원 | 표시가 차이의 단순 환산. 실제 연간권 차액·확정 절감액이 아님 |

| 보조: 연간권과 기존가 유지 비교 | 연간권 115,000원은 기존가 월 유지 합계 118,800원보다 3,800원 적음 | 선납·환불 조건과 쉬는 기간의 비이용 가치를 별도 고려 |

티빙 출처는 [공식 요금제](https://www.tving.com/bill/subscription/plan)와 [한국 App Store](https://apps.apple.com/kr/app/tving/id400101401?platform=ipad)입니다. PRICE-A 확인 시각은 2026-11-14 15:40:45 KST이며, 16:14 KST 가격 검수에서 월간·KRW·세금 근거를 보완했습니다. 계정별 최종 결제 화면은 확인하지 않았습니다.

보조 계산의 출처는 [디즈니+ 정책 변경 안내](https://www.disney.co.kr/notice/update-20261030)입니다. 2026-10-30 발표·11-10 신규/재가입 적용, 조사 자료 확인 시각: 2026-11-14 14:27 KST. 기존가 유지 자격·가격 고정·쉬는 동안 무청구·추가 비용 제외를 가정합니다. 웹 정책을 App Store·Google Play·파트너 결제에 자동 대입하지 않습니다.

## 5. 차별점

똑이는 도구가 계산한 숫자로 먼저 묻고, 사람의 답변과 정책 거부 사유에 따라 다음 행동을 고릅니다. 반대는 조건을 고친 새 제안으로 이어지고, 후속 청구는 같은 사건을 다시 엽니다. 사건 단계와 허용 여부는 결정적 코드가 검사하고, 에이전트는 어떤 도구를 언제 부를지 판단합니다.

메인 녹화의 점검 **5회**는 **711,908ms(711.908초)·MCP 도구 호출 34회·도구 거부 5회**입니다. 이는 실행 기록이며 수요나 절감 효과의 측정값이 아닙니다. 사람의 이전 버전 응답 거부 1건은 도구 거부 5회와 별도입니다. 개발 근거와 기록 범위는 [BUILD_REPORT.md](BUILD_REPORT.md), 요구·코드·시험 연결은 [traceability.md](docs/evidence/traceability.md)를 참고할 수 있습니다.

문자함 전체 자동 수집·자동 해지·실가족 인증·상시 예약 알림은 제공하지 않습니다. 수동 계산과 녹화 재생은 Kiro 없이 확인할 수 있고, 똑이의 새 점검 실행에는 Kiro CLI의 계정·모델 연결이 필요합니다. 모델에 전달하는 자료는 합성 구조화 데이터입니다. 모든 정보가 기기 안에만 남는다고 주장하지 않습니다.

## 6. 설치와 실행

Node.js 22.12 이상과 npm이 필요합니다. Vite·React·TypeScript 웹앱이며 브라우저 저장에는 IndexedDB, 배포에는 GitHub Pages를 사용합니다.

```bash
cd "$HOME/kirothon-team-024"
npm ci
npm run dev
```

터미널에 표시된 로컬 주소를 엽니다. 정적 빌드는 다음 명령을 사용합니다.

```bash
npm run build
```

Kiro CLI가 없거나 로그인하지 않았다면 배포 화면 또는 로컬 웹앱의 **점검 데모**에서 동봉된 기록을 재생합니다. 화면의 "녹화 기록"은 새 봇 실행이 아닙니다.

새 봇 데모 실행에는 Kiro CLI 로그인과 모델 사용 권한이 필요합니다. 다음 명령은 모델을 호출하고 합성 시나리오와 실행 영수증을 갱신합니다.

```bash
npm run bot:demo
```
