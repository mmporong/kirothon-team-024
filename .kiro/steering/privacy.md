# 개인정보 규칙

- 결제 문자 원문은 기본 저장하지 않는다. 확인된 필드와 근거 위치(start·end)만 저장한다.
- 실제 문자·결제 내역·가족 이름·전화번호를 저장소, 테스트, 프롬프트, MCP 응답, 로그에 넣지 않는다. 테스트 자료는 합성(`synthetic: true`)만 쓴다.
- 금지 경로: `~/Library/Messages/`, `chat.db`, 실제 카드·은행 내보내기 파일. Kiro 훅(pretool-guard)이 이 경로 접근을 막는다.
- 내보내기(요약·ICS)는 미리보기 후 사용자가 저장한다. 원문은 기본 제외한다.
- "원문은 기기 안에서 처리"와 "어떤 데이터도 밖으로 나가지 않음"은 다른 주장이다. ICS를 다른 달력에 가져오면 일정 메타데이터가 나갈 수 있음을 표시한다.
